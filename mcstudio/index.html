Skin Studio

Free Minecraft skin editor in the browser. Paint on a live 3D player model or the flat UV map, use layers and templates, undo every stroke, and share a skin with a link — nothing is uploaded to a server. The optional desktop app adds Mojang / PNG import and texture-pack workspaces.

  • 3D skin painter with brush, fill, shapes, and shading tools
  • Layer stack with blend modes and filters
  • Character templates with colors, hair, and accessories
  • Shareable URLs that encode the skin client-side
  • Desktop build for texture packs and Mojang username import
